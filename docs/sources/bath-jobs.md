## Current source decision and permission

The official [RSS directory](https://www.bath.ac.uk/jobs/rss/) explicitly offers feeds for automatic vacancy updates and identifies [Education & Research, category 391](https://www.bath.ac.uk/jobs/rss/rss.aspx?cat=391). The [jobs terms](https://www.bath.ac.uk/jobs/display.aspx?id=322&pid=84) allow personal noncommercial use for applicants/staff; this personal prospective-applicant feed use matches that purpose. [Robots](https://www.bath.ac.uk/robots.txt) does not disallow the jobs RSS path. No account, cookie, authentication, application submission or commercial redistribution is used. This is narrow feed-use approval, not an open-content license for full advertisements. Fixtures will contain handwritten minimal factual transcriptions in the observed RSS structure, with attribution and declared synthetic variants; no original advert prose, contacts or full captured feed will enter Git. Public readability alone is not the permission basis.

One bounded public inspection returned HTTP 200, `text/xml; charset=utf-8`, 220,190 decoded UTF-8 bytes and 19 items. The XML prolog says ISO-8859-1 despite the transport charset; bytes decode strictly as UTF-8 under the existing HTTP port. Record this transport/prolog disagreement without guessing another encoding. The parser consumes an already decoded string, ignores stylesheet processing instructions and never follows them. Exact fields observed: title/link/guid/description/category/pubDate. Description contains the complete HTML advert plus labeled closing date/job family/salary; a feed read needs zero detail requests. No pagination was advertised; a bounded snapshot fails visibly if its size/record ceiling is exceeded. Do not silently truncate it or infer withdrawal from absence.

The feed contains lecturers, KTP associates and clinical fellows as well as postdoctoral roles. Source-local classification requires the Education & Research family plus a supported role title and explicit postdoctoral/PhD-level appointment evidence where needed. A generic `research` word or every Research Fellow is insufficient. Clinical fellows and faculty/support roles receive exclusion codes.

Initial supported types are `research_assistant` and `postdoc`; PhD/internship coverage is a later B gate, not claimed by this pilot. The current feed has explicit Postdoctoral Research Associate entries (`SS14039`, `SS13987`) and Research Associate entries with additional postdoctoral evidence. An earlier official list showed Research Assistant `SS13911`; it is not present in the inspected current feed, so no live assistant is fabricated. Unknown location, work mode, qualifications, nationality and publication time remain unknown unless the individual advert/feed supplies evidence. Institution location is not job location. Publication comes from pubDate, never fetch time. A labeled closing calendar date stays date-only; rolling/missing are explicit unknown-time evidence.

## Bounds and identity

Fixed HTTPS feed only; no click-tracker navigation, external ATS fetch or arbitrary discovered detail URL. One GET/page/run, 15 seconds, 512 KiB decoded response, at most 40 items; zero enrichment requests. Proposed daily cadence only, with existing conditional validators, retry budget, per-host concurrency and cooldown; no schedule is activated. The approved feed host is Bath-owned; no DNS IP pinning is claimed. All links are data, not fetch destinations.

Stable vacancy reference is extracted only from the reviewed `rss/click.aspx?ref=...` GUID/link form, checked against the title's trailing reference. Canonical official URL is the `Vacancy.aspx?ref=...` form confirmed by the manual direct-page and click-target checks below. Reference is the hiring cycle identity; deadlines and publication time never identify it. The same reference updates; a new reference with a similar title remains a new hiring cycle. Changed reference suffix/repost is not an automatic merge.

Canonical descriptions contain bounded factual summaries; qualification/eligibility evidence is structured and bounded, not a full HTML advert in provenance. Original source record, payload revision and field provenance remain traceable through existing RPCs. Unsupported records receive deterministic durable dispositions so page accounting includes every distinct source key.
